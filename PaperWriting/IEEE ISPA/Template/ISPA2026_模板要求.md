# ISPA 2026 投稿模板与格式要求

核验日期：2026-10-01（Asia/Shanghai）。会议明确规定、官方模板行为及 IEEE 通用出版指导分别标注。本次资料整理未修改当前稿件。

## 1. 模板选择

ISPA [CFP 网页](https://ieee-ai-for-science.org/2026/ispa/cfp.php) 指定 IEEE Computer Society Proceedings Format，并链接 [IEEE Template Selector](https://template-selector.ieee.org/)。本次选择器无法解析，未取得交互选择结果；已核实并保存 IEEE 在 Overleaf 发布的 Computer Society conference 示例，以及 IEEE Computer Society 官方媒体域名的 Word 模板。

LaTeX 起点为 [ispa2026_bare_conf_compsoc.tex](ispa2026_bare_conf_compsoc.tex)：

```latex
\documentclass[conference,compsoc]{IEEEtran}
```

来源：[IEEE Demo Template for Computer Society Conferences](https://www.overleaf.com/latex/templates/ieee-demo-template-for-computer-society-conferences/hzzszpqfkqky)。这是官方通用 Computer Society 会议骨架，不是 ISPA 定制类文件。conference 为会议模式，compsoc 为 Computer Society 样式。

## 2. 版式、纸张和署名

| 项目 | 执行方式 | 依据与限定 |
|---|---|---|
| 正文 | 双栏、10 pt 默认设置 | IEEEtran conference/compsoc |
| 默认纸张 | US Letter，8.5 × 11 英寸（612 × 792 pt） | 当前 LaTeX 默认及下载的 Word 版本；ISPA CFP 未另行限定 Letter/A4 |
| A4 | 类文件支持 a4paper，是否采用须服从会议/EDAS | 支持选项不等于本届强制或允许该尺寸 |
| 字体、页边距、栏距和行距 | 保留模板默认值 | 官方骨架与 CPS 指南均要求不要手工改变 |
| 页码和页眉页脚 | 不自行加页码或装饰性页眉页脚 | CPS 指南；会议指定版权行按后续正式通知 |
| 标题和作者 | 使用模板标题块及作者块，署名与 EDAS 一致 | 本届单盲，保留真实作者和单位 |
| 语言 | 英文 | CPS 配套指南 |
| 占位内容 | 删除模板中的演示文字、示例作者和说明 | 模板使用要求 |

不得通过缩小正文或改写类文件挤页。Full Regular Paper、Regular Paper 和专题会限制不同，见 [会议要求](../sources/ISPA2026_投稿要求汇总.md)。CFP 未声明参考文献或附录免计页数，准备时按 PDF 总页数控制。

## 3. 摘要、关键词和章节

LaTeX 骨架建议摘要一般不放公式、特殊符号和引用；CPS Word 指南对标题和摘要也有相应说明。未查到本届独立的摘要字数上限，不将其他会议常见的 200 字或期刊的 150–250 字写成本届规定。

关键词存在模板示例差异：bare_conf_compsoc.tex 注释写 no keywords，CPS Word 示例则包含 Keywords。ISPA CFP 未规定数量或是否必需，应以本届明确要求或所选正式模板为准，不能据此直接认定当前稿件的关键词违规。

章节编号、字体和间距由模板处理。Computer Society 骨架使用不编号的 Acknowledgments。附录、作者简介及补充材料的本届专门要求尚未查到。

## 4. 文献、公式和图表

| 对象 | 模板要求或指导 |
|---|---|
| 文献样式 | IEEE 格式；骨架提供 `\bibliographystyle{IEEEtran}`，本地有 IEEEtran.bst |
| 正文引用 | 数字引用；Computer Society 骨架使用 `\usepackage[nocompress]{cite}`，不压缩连续编号 |
| 引用信息 | 由模板/BibTeX 管理，核对作者、题名、出处、年份和可用 DOI；不用 GB/T 7714 替代 IEEE 投稿样式 |
| 公式 | 使用数学排版、定义符号、按模板编号，避免超栏 |
| 图表宽度 | 单栏用 figure/table，跨栏用 figure*/table*；尺寸服从实际栏宽 |
| 题注 | 图题在下、表题在上；label 位于 caption 之后或内部 |
| 子图 | 若使用 subfig，注意骨架中的 caption=false，避免覆盖 IEEEtran 题注样式 |
| 清晰度 | 按最终栏宽检查；线型、标记辅助颜色区分，检查灰度可读性 |

依据：[官方骨架](ispa2026_bare_conf_compsoc.tex)、[CPS 指南](Word/instruct8.5x11x2.pdf)、[IEEE 图形指导](https://conferences.ieeeauthorcenter.ieee.org/write-your-paper/improve-your-graphics/)。

IEEE 图形指导接受 PS、EPS、PDF、PNG、TIFF，以及在 Office 原生绘制的相应图形文件；其高分辨率 JPEG 使用场景限于作者照片。图形字体应嵌入或转轮廓。网页建议最终图内文字约 9–10 pt，而 CPS Word 的标签示例为 8 pt；不要据此统一缩小图内文字，应按最终尺寸保持清晰。IEEE 不再接受含 Lena 图像的投稿。完整指导见 [检索文本](official_sources/ieee_graphics_requirements.web-extract.txt)。

## 5. PDF 要求

ISPA CFP 网页明确要求嵌入全部字体，并避免扫描稿、文字转换错误、加密及过时的 Type 3 字体；这些问题可能导致上传失败。

IEEE 通用 [Meet IEEE Xplore Requirements](https://conferences.ieeeauthorcenter.ieee.org/write-your-paper/meet-ieee-xplore-requirements/) 另列出版 PDF 检查：电子生成而非扫描；字体嵌入或子集嵌入；无密码或安全限制；无书签和链接；无裁切/套准标记、印在页面上的时间戳等非正式内容；无覆盖生成设置的 PostScript 设置；无 PDF 附件；不是 PDF Package 或合并封装文件。原页面的版本条目同时使用 PDF 1.4 与旧 Acrobat 产品名，保存在 [检索文本](official_sources/ieee_xplore_requirements.web-extract.txt)，不自行推定新的版本上限。最终以会议指定工具的验证结果为准。

该页面说明并非所有 IEEE 会议均用 PDF eXpress。本届 conference ID、邀请链接及初投是否需验证尚未公开，收到本届说明后执行。通用 IEEE PDF Checker、LaTeX 和参考文献检查工具可辅助核查；本地编译通过不等于 EDAS 或 PDF eXpress 通过。

## 7. 当前目录中的使用方式

在本目录使用骨架时，类文件与样式文件位于同目录。若主稿位于上一级，应配置 TeX/BibTeX 搜索路径或随稿打包相应依赖，并一并提供稿件自己的图片和文献库；只移动主 tex 文件不足以构成完整项目。

保存后核查实际 PDF 的总页数、字体、超栏、引用解析及图表可读性；提交时核对类别和元数据，并确认上传及验证结果。本次只整理要求和官方模板，没有生成或替换当前论文 PDF。
